# FemFactory website concept

Built by Zak Studio from FemFactory's public OTJ profile (https://theotj.com/explore/femfactory).

- `index.html`: the whole site (HTML, CSS, JS in one file). Text is in the `T` object (English and Arabic). Services are in the `C` list.
- Background and case-study pictures are generated artwork inside the CSS (search for BACKGROUND PICTURES). Replace with real photos by uploading them and changing the url(...) lines.
- Items marked PLACEHOLDER (case studies, client logos, testimonials, pricing, contact details) are sample content. Replace with real material.

Edit any file on GitHub, commit, and the site updates in about a minute.
